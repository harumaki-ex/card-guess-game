# 16模様カード当て・オンライン完成版

## できること
- ルーム作成
- 6文字のルームコード自動発行
- ルームコードで参加
- プレイヤー名
- 2人リアルタイム対戦
- WebSocket通信
- ゲーム終了時の勝敗表示
- ゲーム画面を同じNode.jsサーバーから配信

## ローカルで起動

Node.js 18以上を用意してください。

```bash
npm install
npm start
```

ブラウザで:

```text
http://localhost:3000
```

を開きます。

1人目 → 「ルームを作成」
2人目 → 同じURLを開いて「ルームに参加」
1人目に表示された6文字のコードを2人目に入力。

## インターネット公開

このプロジェクトは、HTTPとWebSocketを同じNode.jsサーバーで処理する構成です。
そのため、WebSocket対応のNode.jsホスティングにこのフォルダをそのまま配置すれば、同じURLから他の人が参加できます。

必要な起動コマンド:

```bash
npm start
```

ホスティングサービスから `PORT` 環境変数が渡された場合にも対応しています。

## 重要
このサーバーはメモリ上にルームを保持します。
サーバーを再起動すると、作成中のルームは消えます。
また、現状は1ルーム2人制です。
